# BD.Standard.弥费.ReportServicePlugIn 项目代码描述

## 核心报表插件

### 1. InvAgeDetailRptExport.cs (库龄分析明细报表服务插件)
- **功能定位**：继承自金蝶标准库龄分析报表，通过重写 `BuilderReportSqlAndTempTable` 方法实现批号日期解析与库龄天数重算
- **核心逻辑**：
  - 从过滤条件中获取查询日期（`QueryDate`）和是否包含当天标志（`CurDateIsOne`）
  - 动态构建SQL更新语句，处理四种批号日期格式：
    1. 头部10位 yyyy-MM-dd 格式
    2. 头部8位 yyyymmdd 格式
    3. 尾部10位 yyyy-MM-dd 格式
    4. 尾部8位 yyyymmdd 格式
  - 使用 `ISDATE()` 函数验证日期有效性，并确保计算日期小于查询日期
  - 计算库龄天数时根据 `CurDateIsOne` 决定是否加1天
- **技术特点**：
  - 使用动态SQL（EXEC）执行批量更新
  - 采用CASE WHEN多条件判断处理不同日期格式
  - 注释掉的代码显示曾考虑过滤库龄≤0天的数据

### 2. InOutStockDetailServiceExport.cs (存货收发存明细报表服务插件)
- **功能定位**：继承自标准存货收发存报表，扩展批号过滤功能
- **核心逻辑**：
  - 获取过滤条件中的批号（`FLOTNO`）
  - 当批号不为空时：
    1. 删除表中不包含指定批号的数据
    2. 使用CTE（公用表表达式）和ROW_NUMBER()重置标识列（`fidentityid`）
- **技术特点**：
  - 使用动态SQL进行条件删除
  - 采用CTE实现标识列重新编号
  - 仅在批号过滤条件存在时执行扩展逻辑

### 3. BillPluginTwo.cs (库龄分析汇总过滤表单插件)
- **功能定位**：扩展库龄分析汇总界面的过滤方案管理
- **核心功能**：
  - 方案加载：从存储过程读取自定义过滤方案
  - 条件回填：解析XML配置，自动回填查询日期、物料、仓库等条件
  - 数据联动：处理库龄区间变动和方案切换
  - 数据导出：调用WebAPI获取数据并持久化到自定义表

### 4. ReportPlugInTwo.cs (报表服务插件)
- **功能定位**：基于项目结构推断为库龄汇总报表的服务端数据查询插件
- **预期功能**：
  - 重写报表SQL生成逻辑
  - 扩展临时表数据处理
  - 可能包含批号日期解析等自定义计算

## 项目特点
1. **报表定制化**：通过继承标准报表类，实现特定业务逻辑扩展
2. **动态SQL处理**：大量使用动态SQL满足复杂计算需求
3. **批号日期解析**：支持多种批号日期格式，提高数据兼容性
4. **过滤方案管理**：提供灵活的报表过滤条件管理机制
5. **热更新支持**：所有插件标记为 `HotUpdate`，支持不停机更新
